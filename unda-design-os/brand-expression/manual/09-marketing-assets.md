# 9. Marketing Assets

> Not yet in production — see [the scope note](../README.md#an-honest-note-on-scope). These are ready-to-produce standards for when a real campaign, post, or event needs one of these asset types.

Every asset below shares the same foundation: General Sans typography ([Typography tokens](../../design-system/tokens/typography-tokens.md)), the locked color tokens, the logo lockup rules ([Logo system](../../brand/logo-system.md)), and the [Graphic language](./07-graphic-language.md) for any background/pattern element. What varies per format is dimension and information density, not the visual system.

## Social graphics

Platform-native dimensions (square 1:1, portrait 4:5, story 9:16). One headline, one supporting line maximum, logo symbol-only lockup in a corner respecting its [clear space rule](../../brand/logo-system.md#3-clear-space--minimum-size). Division accent color signals which division the post is about.

## Blog covers

16:9, headline in `type.display` or `type.h1` scale, minimal or no photography — prefer a graphic-language treatment (module pattern, radial system) over a generic stock photo cover.

## Keynote slides / pitch decks

See [Presentation System](./10-presentation-system.md) for the full slide-type spec — these are governed by that section, not independently.

## Conference banners / event signage

Large-format versions of the same hero composition rules ([Layout language](./02-layout-language.md)) — one headline, one logo lockup, generous margins scaled to viewing distance (type must be legible from the expected furthest viewing point, not just up close).

## LinkedIn / X graphics

Same rules as social graphics, sized to each platform's current recommended dimensions at time of production (platform specs change — don't hardcode a dimension here that will go stale; check the platform's current guidance).

## YouTube thumbnails

High contrast, one clear focal point, minimal text (large enough to read at thumbnail scale) — logo symbol-only, never the full lockup (too small to read at thumbnail size, per the [16px digital symbol-only minimum](../../brand/logo-system.md#3-clear-space--minimum-size)).

## Newsletter headers

Horizontal lockup, division accent if division-specific content, otherwise brand primary. Matches the [horizontal lockup](../../brand/logo-system.md#2-wordmark--lockup) use case exactly (nav bars, letterhead — a newsletter header is functionally the same context).
