# 10. Presentation System

> Not yet in production — see [the scope note](../README.md#an-honest-note-on-scope).

A deck should read like the rest of the brand: one idea per slide, typography-led hierarchy, restrained color, generous whitespace. Built on the same 12-column-equivalent grid as everything else ([Layout language](./02-layout-language.md)), scaled to a 16:9 canvas.

## Title slides

Logo lockup (stacked or horizontal), deck title in `type.display`, presenter/date in `type.caption`. Nothing else — a title slide is the one place full symmetry is appropriate.

## Section dividers

Division accent color as the full-bleed background if the deck covers multiple divisions, section title in `type.h1`, no supporting copy.

## Charts

Follow [Data Visualization](./08-data-visualization.md) exactly — one metric, largest size, muted supporting series. A chart slide title states the takeaway ("Revenue grew 40% QoQ"), not a generic label ("Q3 Revenue Chart").

## Timelines

Built from the [Graphic language](./07-graphic-language.md) hairline-divider primitive with milestone markers — never a decorative "roadmap" illustration with unrelated iconography.

## Comparison slides

Real tables where the comparison is genuinely tabular ([Table & list](../../design-system/components/table-and-list.md) conventions) — avoid ad-hoc side-by-side boxes when a table communicates the same information more scannable.

## Quotes

Attributable, named quotes only, set in `type.h3` or `type.h4` — matches [Testimonials pattern](../../design-system/patterns/testimonials.md): a vague, unattributed quote undermines trust rather than building it, on a slide same as anywhere else.

## Case studies

Problem → approach → measurable outcome, one per slide or slide sequence — never a portfolio-gallery slide of finished screens with no narrative ([Case study pattern](../../design-system/patterns/case-study.md)).

## Appendix

Documentation-density rules apply here, not marketing-density rules ([Layout language: documentation layouts](./02-layout-language.md)) — an appendix can be denser than the main deck since it's reference material, not a presented narrative.
