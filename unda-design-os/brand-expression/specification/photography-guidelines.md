# Photography Guidelines

Production spec for [Photography Direction](../manual/03-photography-direction.md).

## Technical specs

| Use | Resolution | Aspect ratio | Format |
|---|---|---|---|
| Website hero | ≥2400px wide | 16:9 or 3:2 | WebP (delivery), original RAW/TIFF archived |
| Card/thumbnail | ≥800px wide | 4:3 or 1:1 | WebP |
| Social | Platform-native minimum (check current platform spec) | Platform-native | JPEG/WebP per platform requirement |
| Print | 300dpi at final print size | Per collateral type | TIFF/high-quality JPEG |

## Grading parameters

- White balance: neutral (5000–5600K equivalent, no strong warm/cool cast)
- Saturation: moderate — natural, not vivid
- Contrast: soft-to-moderate, no crushed blacks or blown highlights
- No filter presets, no HDR tone-mapping, no duotone/black-and-white treatment as a default style

## File handling

- Always retain and archive the original/RAW capture — web exports are derived, not the source of record.
- Every photo used publicly needs a model/location release on file where people or private property are identifiable.

## Do / don't checklist

- [ ] One clear subject, tightly cropped
- [ ] Natural or naturalistic lighting only
- [ ] Real environment, real people, real work — not staged stock
- [ ] Neutral grading — no filter, no HDR, no dated color treatment
- [ ] If depicting African subjects/settings: modern, competent framing — no poverty or landscape-only cliché (see [Expression Principles §7](../manual/01-expression-principles.md))
- [ ] Release on file for identifiable people/private property
