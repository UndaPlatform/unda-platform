# QA Checklist

Run before publishing any new brand-expression asset. This is the expression-layer equivalent of [Accessibility rules' per-component testing checklist](../../design-system/rules/accessibility-rules.md) — same spirit, applied to marketing/brand assets rather than interface components.

## Every asset

- [ ] Uses only locked tokens — color, type, spacing, radius, motion (no invented hex/px/duration values)
- [ ] Logo usage (if present) follows [Logo system](../../brand/logo-system.md) exactly — correct lockup, correct clear space, correct color variation, no misuse
- [ ] Named per [Asset naming conventions](./asset-naming-conventions.md)
- [ ] Meets the relevant [Accessibility guidance](./accessibility-guidance.md) checklist (alt text, contrast, captioning, motion safety as applicable)
- [ ] Checked against [Expression Principles](../manual/01-expression-principles.md) — restrained, clear, systems-consistent

## Photography-specific

- [ ] Passes the [Photography guidelines](./photography-guidelines.md) do/don't checklist
- [ ] Release on file for identifiable people/private property

## Illustration-specific

- [ ] Passes the [Illustration specification](./illustration-specification.md) checklist

## Icon-specific

- [ ] Passes the [Icon rules](./icon-rules.md) checklist

## Marketing / presentation-specific

- [ ] One idea per asset/slide — a second reviewer can state the takeaway in one sentence
- [ ] Reviewed against the [three design-review questions](../../design-system/rules/design-review-principles.md) before any subjective/aesthetic feedback

## Physical collateral-specific (before commissioning production)

- [ ] Confirmed this is a real, approved need — not speculative production of an item from [Brand in Practice](../manual/11-brand-in-practice.md)'s not-yet-produced list
- [ ] Print specs meet minimum size/bleed/resolution requirements in [Design tokens](./design-tokens.md)
