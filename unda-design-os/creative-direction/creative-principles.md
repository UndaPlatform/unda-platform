# 11. Creative Principles

Eighteen principles every designer, developer, or agent should hold when creating anything under the Unda ecosystem.

1. Typography leads. Reach for a type change before a color change.
2. Whitespace is a decision, not what's left over.
3. Hierarchy comes from scale, weight, and position — color guides, it doesn't decide.
4. One idea per screen, one primary action per view.
5. If a component needs a caption to explain itself, redesign the component.
6. Restraint is a form of confidence — say less, more clearly.
7. Never add an element because a layout feels empty; fix the layout instead.
8. Consistency compounds — the tenth screen should feel as considered as the first.
9. Motion explains cause and effect; it never performs.
10. Design for the decade, not the trend cycle.
11. Every division speaks the same visual language in a different register — never a different language.
12. Accessibility is a baseline requirement, not a later pass.
13. A real photograph beats an illustrated metaphor, almost always.
14. If in doubt, remove the element and see if anything is actually lost.
15. Numbers and data are set in Geist Mono; nothing else is.
16. Craft shows in the details no one will consciously notice — alignment, spacing, kerning.
17. Copy should say precisely what the product does, in the words a user would use.
18. Systems scale; one-off decisions don't. Solve the pattern, not the instance.

These principles govern every subjective design review across every division — see [`../brand/governance.md`](../brand/governance.md) for how additions to this system get proposed and approved.
