# 10. Cross-Brand Consistency

All four brands share one grid, one type system, and one design philosophy. Each division is differentiated only by its accent color and by which parts of the visual language it emphasizes — never by a different typeface, grid, or set of principles.

| Division | Accent | Register |
|---|---|---|
| Unda Solutions | Royal Blue | Corporate. Confident, understated, institutional. |
| Unda Studio | Orange | Creative. The most editorial and expressive division, within the shared system. |
| Unda Technologies | Cyan | Technical. Developer-first, dense-when-useful, precise. |
| Unda Travel | Emerald | Warm. The most human and image-led division; still built on the same grid. |

A user moving from undasolutions.com to any division subdomain should feel they've moved to a specialized room in the same building — not a different building.

This matches the division-accent architecture already documented in [`../brand/architecture.md`](../brand/architecture.md); literal hue values live in [`../design-system/tokens/color-tokens.md`](../design-system/tokens/color-tokens.md).
