# 4. Layout Philosophy

Every surface sits on a single underlying grid — a consistent column count and gutter that marketing pages, product screens, and documents all inherit, so a user moving between a marketing site and a product dashboard never feels a seam.

- **Page rhythm** — long pages are built from a small set of repeating section types, not one-off layouts per page.
- **Content flow** — one clear reading path per screen; never two competing focal points.
- **Container widths** — marketing copy reads best in a constrained measure (roughly 60–75 characters per line); product tables and dashboards are allowed to use the full viewport.
- **Whitespace strategy** — whitespace scales with the importance of what it surrounds. The most important statement on a page gets the most air.
- **Responsive thinking** — hierarchy is designed once and re-flowed, never redesigned per breakpoint; what is large and first on desktop stays large and first on mobile.

Literal grid, container, and breakpoint values live in [`../design-system/foundations/grid-and-breakpoints.md`](../design-system/foundations/grid-and-breakpoints.md) and [`../design-system/tokens/spacing-grid-and-border-tokens.md`](../design-system/tokens/spacing-grid-and-border-tokens.md).
