# Overview & Foundational Decisions

Source: *Unda Solutions — Creative Direction v1.0* (internal creative handbook, August 2026). This document precedes [`../design-system/`](../design-system/index.md) — it defines the creative *reasoning*, not colors, pixels, or components. Read this before opening a design tool.

## How to use this document

This defines the creative language of Unda Solutions before any interface is designed. It specifies the reasoning that later produces a consistent, timeless design system across Unda Solutions, Unda Technologies, Unda Studio, and Unda Travel. Every future designer, developer, or AI agent should read this before starting work.

## Foundational decisions (final, not open for reinterpretation)

| Context | Typeface |
|---|---|
| Marketing & brand | General Sans |
| Product interfaces | Geist |
| Monospace / data | Geist Mono |

The governing design philosophy, also final: **clarity over complexity, craft over decoration, systems over trends.** Whitespace is a feature, not empty space. Typography carries hierarchy before color does. Every component belongs to one unified system.

These decisions are elaborated with literal values in [`../design-system/tokens/typography-tokens.md`](../design-system/tokens/typography-tokens.md).
