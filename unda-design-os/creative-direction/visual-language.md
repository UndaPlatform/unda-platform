# 2. Visual Language

The visual identity is structural before it is decorative. Every screen and page is built as a grid of deliberate relationships — between a headline and the text beneath it, between a card and the ones beside it, between an image and the copy that explains it. Nothing sits at an arbitrary size or position.

- **Balance** — compositions are asymmetric but weighted; a large element on one side is answered by density, not another large element, on the other.
- **Contrast** — achieved through scale and weight (a very large headline against very small metadata), rarely through color.
- **Hierarchy** — established by type size, spacing, and position, in that order — color is the last resort, never the first.
- **Rhythm** — sections repeat a consistent vertical cadence (generous, identical spacing units) so scrolling feels metered, not random.
- **Alignment** — everything sits on one shared grid; nothing is centered simply because centering was convenient.
- **Density** — low by default. Product surfaces (dashboards, tables) may run denser than marketing surfaces, but never dense enough to require visual searching.
