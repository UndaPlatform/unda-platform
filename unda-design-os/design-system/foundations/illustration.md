# Illustration

## Philosophy

Illustrations explain, they don't decorate. Every illustration should answer "what does this help the user understand?" — if it doesn't improve understanding, reconsider it. Illustration plays a *supporting* role in this brand, not a dominant one; the brand doesn't rely on decorative artwork the way many consumer brands do.

## Style: minimal geometric illustration

Simple geometric forms, rounded corners, limited detail, soft shadows, clean composition, consistent proportions, flat or lightly-layered. Avoid overly detailed, cartoon-like, or highly realistic illustration — that's a different brand entirely.

## Color usage

Neutral palette as the foundation, primary brand color for emphasis, division accent colors where contextually appropriate, semantic colors only for status. No rainbow palettes or arbitrary color variation.

## Shape language

Illustrations inherit the same [shape language](./radius-and-borders.md) as the rest of the system — rounded rectangles, circles, straight lines, consistent corner radii — so an illustration reads as an extension of the interface, not separate artwork pasted on top.

## Composition rules

One idea per illustration. Avoid visual clutter. Generous whitespace. Clear hierarchy guiding the viewer's attention. Break complex ideas into multiple smaller illustrations rather than one dense scene.

## Human representation

Diverse, non-stereotyped, minimal facial detail, focus on actions rather than appearance, approachable professional poses. People should read as relatable, not as caricatures.

## Technology representation

Represent technology **abstractly** — connected systems, modular blocks, data flow, networks, dashboards, devices, cloud infrastructure. Explicitly avoid the clichés that date fast: glowing brains, floating robots, circuit-board backgrounds, binary code overlays, lightbulbs, rocket ships.
