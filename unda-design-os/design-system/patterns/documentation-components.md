# Documentation Components

Source: *Design System v1.0*, §V. Code block, callout, and API reference table used across developer-facing Unda Technologies surfaces.

**Rules** — code block: `type.code` on a `neutral.900` surface regardless of page theme, copy button on hover, syntax highlighting limited to 4 muted hues. Callout: `status.*` tokens only, icon + label + body. API table: monospace parameter names, plain-language descriptions, required params marked with a small dot — never a red asterisk.

**Accessibility** — copy button announces "Copied" via a live region; code block is keyboard-focusable and selectable without a mouse.

**Figma spec** — `CodeBlock`, `Callout`, `ApiTable` Component Sets living on the Documentation Patterns page.
