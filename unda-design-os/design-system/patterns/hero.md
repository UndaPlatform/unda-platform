# Hero

Source: *Design System v1.0*, §V. Assembled from [Button](../components/button.md) and [Link](../components/link.md); see intent in [Component philosophy](../../creative-direction/component-philosophy.md).

**Purpose** — the first thing a visitor sees; earns the rest of the scroll.

**Content rules** — states what the visitor gets, in one sentence, before it states anything about the company.

**Responsive** — stacks to a single column below `md`.

**Accessibility** — heading structure starts at `h1`; any supporting media has meaningful `alt` or is marked decorative.

**Figma spec** — lives as a Pattern (assembled template), not an atomic component — references the same underlying [Button](../components/button.md) and text-style tokens rather than duplicating styling.
