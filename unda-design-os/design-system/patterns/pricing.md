# Pricing

Source: *Design System v1.0*, §V. Assembled from [Card](../components/card.md) and [Button](../components/button.md).

**Purpose** — present plans transparently and let one clear recommendation stand out.

**Content rules** — transparent by default; one plan may be recommended through typographic emphasis only, never an aggressive visual frame.

**Responsive** — pricing cards stack vertically with the recommended plan moving to the top.

**Accessibility** — the plan comparison is available as a real table for screen reader users, not only as visually adjacent cards.

**Figma spec** — a Pattern referencing the same underlying [Card](../components/card.md) and [Button](../components/button.md) Component Sets rather than duplicating styling.
