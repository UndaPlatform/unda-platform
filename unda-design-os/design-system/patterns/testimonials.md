# Testimonials

Source: *Design System v1.0*, §V. Assembled from [Avatar](../components/avatar-timeline-and-empty-loading-states.md) and [Card](../components/card.md).

**Purpose** — build trust with specific, attributable proof, not generic praise.

**Content rules** — specific results from named, attributable people. A vague quote with a stock headshot undermines more trust than it builds.

**Figma spec** — a Pattern built from [Card](../components/card.md) and [Avatar](../components/avatar-timeline-and-empty-loading-states.md) Component Sets.
