# Travel Card

Source: *Design System v1.0*, §V. Assembled from [Card](../components/card.md).

**Purpose** — sell a destination or itinerary on feeling first, detail second. The one component/pattern permitted to lead with imagery — see [Art direction](../../creative-direction/art-direction.md), which otherwise restricts imagery to a supporting role.

**Responsive** — image keeps a fixed 16:10 crop at every width.

**Figma spec** — a Pattern built from the [Card](../components/card.md) Component Set with a locked media aspect ratio.
