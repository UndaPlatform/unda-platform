# Design Review Principles

Source: *Design System v1.0*, §I.

## Design goals, in priority order

1. **Consistency** across four brands and every surface.
2. **Accessibility** as a floor.
3. **Longevity** over trend-following.
4. **Speed of assembly** for new products.

When goals conflict, resolve in this order — consistency wins over a locally "nicer" one-off, accessibility is never traded for either, and speed of assembly is the last consideration, not the first.

## The three questions every review asks, before any subjective feedback is given

1. Does it use existing tokens and components?
2. Does every required state exist?
3. Does it hold up against [Creative Direction](../../creative-direction/index.md)'s constraints?

**Aesthetic preference is the last thing discussed, not the first.** A reviewer (human or AI) that leads with "I'd prefer this in a different color" before checking these three questions is reviewing wrong.
